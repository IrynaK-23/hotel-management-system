# Hotel Management System

Програма для роботи адміністратора готелю.

Мета моєї курсової роботи — створити програму, яка допоможе адміністратору готелю працювати з номерами, гостями та бронюваннями.

## Що має бути в програмі

- номери трьох категорій з різними цінами та кількістю місць;
- облік гостей готелю;
- бронювання номерів на певні дати;
- перевірка, чи вільний номер;
- автоматичний вибір номера, щоб було менше вільних проміжків між бронюваннями;
- зміна стану бронювання (створено, підтверджено, заселено, виселено, скасовано, незаїзд);
- штраф за пізнє скасування;
- розрахунок ціни залежно від сезону, дня тижня та додаткових послуг;
- таблиця зайнятості номерів і звіт про заповненість готелю;
- меню для роботи з програмою.

## Python і C++

На C++ планую зробити перевірку вільних номерів, автоматичний вибір номера та розрахунок ціни.

Python буду використовувати для меню програми та звітів.

Як саме з'єднати C++ і Python, вирішу під час подальшої роботи.

## Структура проєкту

```text
cpp/
  include/
    Room.h       клас номера готелю
  src/
    main.cpp     початкова програма C++

python/
  main.py        початкове меню

README.md        опис проєкту
```

Пізніше планую додати класи для гостей, бронювань і тарифів, а також інші необхідні файли.

## ООП і патерни

У роботі буду використовувати основні принципи ООП: інкапсуляцію, наслідування, поліморфізм та абстракцію.

Також планую використати три патерни:

- State — для зміни станів бронювання;
- Strategy — для розрахунку ціни;
- Decorator — для додаткових послуг.
## Можливі ризики

Під час розробки програми можуть виникнути деякі труднощі:

- **Взаємодія C++ і Python.** Можуть виникнути проблеми з передачею даних між двома мовами. Планую розглянути pybind11 та спочатку перевірити їхню взаємодію на простому прикладі.
- **Бронювання номерів.** Потрібно правильно перевіряти, чи вільний номер на вибрані дати, щоб не виникало подвійних бронювань. Для цього планую окремо реалізувати перевірку доступності.
- **Збереження даних.** Є ризик втрати інформації про гостей і бронювання після закриття програми. Потрібно продумати спосіб збереження даних у файлах або базі даних.
- **Розрахунок вартості.** Можуть виникнути помилки при розрахунку ціни за проживання, особливо якщо будуть різні категорії номерів і додаткові послуги. Планую перевіряти розрахунки на різних прикладах.
- **Тестування.** Деякі помилки можуть бути непомітними під час звичайної роботи програми. Тому потрібно перевірити різні ситуації, наприклад бронювання зайнятого номера, неправильне введення даних або скасування бронювання.
